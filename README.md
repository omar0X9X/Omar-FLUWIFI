# هرم خوفو — Cinematic Reel 9:16

ريل وثائقي عمودي **9:16** مصمم ليشتغل تلقائياً كفيديو قصير، بدون أزرار أو واجهة مستخدم.

## الشكل

- يبدأ تلقائياً عند فتح الصفحة.
- لا توجد أزرار أو شريط تقدم أو عناصر تحكم.
- 13 مشهداً متتابعاً.
- المدة الإجمالية أكثر من دقيقة.
- النصوص قصيرة ومخصصة للعرض فوق الفيديو.
- حركة كاميرا مختلفة بين المشاهد.
- Dust / glow / scan / muon / light effects.
- انتقالات سينمائية سريعة بين المشاهد.
- مناسب للتسجيل على 1080×1920 ثم إضافة التعليق الصوتي والموسيقى في برنامج المونتاج.

## تعديل النص والمدة

داخل `app.js` توجد المصفوفة `scenes`.

كل مشهد يحتوي على:

- `duration`
- `kicker`
- `title`
- `subtitle`
- `visual`

لا يوجد مسار صوت داخل المشروع؛ التعليق الصوتي يضاف لاحقاً في المونتاج كما هو مقصود.

## العرض

المشروع مصمم بنسبة 9:16. على الهاتف يملأ الشاشة، وعلى الحاسوب يظهر بإطار رأسي بنفس النسبة.
